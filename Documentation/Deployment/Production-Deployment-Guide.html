🛠️ Quick Deployment Steps

1
Prerequisites Installation

Install all required development tools and configure your environment for Azure deployment.

# Install Azure CLI Invoke-WebRequest -Uri https://aka.ms/installazurecliwindows -OutFile .\AzureCLI.msi Start-Process msiexec.exe -ArgumentList "/I AzureCLI.msi /quiet" -Wait # Verify installations dotnet --version # .NET 8.0 node --version # Node.js 18+ docker --version # Docker Desktop az --version # Azure CLI

2
Azure Infrastructure Setup
# Login and set subscription az login az account set --subscription "your-subscription-id" # Navigate to project cd "H:\Saas demo d\NewPrimusSaaSFramework" # Run infrastructure deployment .\deploy\azure-setup.ps1 -ResourceGroupName "rg-saas-prod" -Location "East US" -Environment "production"
3
Deploy Applications
# Deploy all containers and services .\deploy\deploy-containerapps.ps1 -ResourceGroupName "rg-saas-prod" -Environment "production" # This deploys: # - Gateway Service (API routing) # - Authentication Service (JWT & user management) # - RBAC Service (roles & permissions) # - Notifications Service (email & messaging) # - Angular Frontend (user interface)
4
Verify Deployment
