🔄 Data Flow Architecture

1

Client Request

Angular frontend sends authenticated request with tenant context and JWT token

2

API Gateway Processing

YARP gateway validates JWT, extracts tenant context, and routes to appropriate microservice

3

Service Authorization

Microservice validates permissions through RBAC service and tenant isolation

4

Data Processing

Service processes request with tenant-partitioned data from Cosmos DB

5

Response & Monitoring

Response returned via gateway with telemetry data sent to Application Insights
