🔒 Authentication & Authorization

All API endpoints require authentication using JWT Bearer tokens. Include the token in the Authorization header for all requests.

Authorization: Bearer {your_jwt_token} X-Tenant-Id: {tenant_id} // Required for multi-tenant endpoints

🎫 JWT Token Structure

• User ID and tenant context

• Role and permissions

• Token expiration (24 hours)

• Refresh token for renewal

🔄 Token Refresh

• Automatic token refresh

• 15-day refresh token validity

• Secure token rotation

• Session invalidation support

🔐 Authentication Endpoints

User Authentication

POST /api/v2/auth/login
Authenticate a user and receive JWT access and refresh tokens. Supports both email/password and Azure AD authentication.
Parameter Type Required Description
email string Required User's email address
password string Required User's password (min 8 characters)
tenantId string Optional Specific tenant to authenticate against
rememberMe boolean Optional Extend token validity (default: false)

📤 Request Example

{ "email": "user@company.com", "password": "SecurePass123!", "tenantId": "tenant-uuid-here", "rememberMe": true }

📥 Response Example

{ "success": true, "data": { "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "refreshToken": "rt_eyJhbGciOiJIUzI1NiI...", "expiresIn": 86400, "user": { "id": "user-uuid", "email": "user@company.com", "firstName": "John", "lastName": "Doe", "tenantId": "tenant-uuid", "roles": ["user"], "creditBalance": 1000 } }, "message": "Login successful" }
200 OK

Authentication successful, tokens returned

400 Bad Request

Invalid email format or missing required fields

401 Unauthorized

Invalid credentials or account locked

429 Too Many Requests

Rate limit exceeded - too many login attempts
